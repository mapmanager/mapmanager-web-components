# Example clients

The best integration examples are applications that use the components in
real workflows.

## AcqView

[AcqView](https://github.com/mapmanager/acqview) uses the Vue Image Viewer with
an `AsyncPlaneSource` adapter for acquisition data.

- [Source repository](https://github.com/mapmanager/acqview)
- [Static application](https://mapmanager.github.io/acqview/)

## CloudScope Web

[CloudScope Web](https://github.com/mapmanager/cloudscope-web) embeds the
NicePool Custom Element and coordinates it with the application selection
model.

- [Source repository](https://github.com/mapmanager/cloudscope-web)
- [Static application](https://mapmanager.github.io/cloudscope-web/)
- [Application documentation](https://mapmanager.github.io/cloudscope-web/docs/)

These clients are examples, not normative API specifications. The component
source and this documentation define current behavior.
